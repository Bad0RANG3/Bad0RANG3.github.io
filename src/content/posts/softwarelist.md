# 🧰 电脑软件实用清单

> 一份面向普通用户的电脑软件推荐清单 —— 开箱即用、不折腾、装完就能干活。

> **推荐原则**
> - **优先推荐开箱即用的软件**，避免需要命令行、脚本配置或复杂折腾的工具。
> - 当某软件存在明显会员墙、广告或体验限制时，会补上更好的免费平替。
> - 所有软件优先从官网或官方商店下载，别碰第三方捆绑打包站。

## 🚀 快速入口

- **新电脑先装**：浏览器、压缩、搜索、卸载、截图、下载器、播放器、输入法
- **学生 / 轻办公**：Office、PDF、笔记、思维导图、云同步、邮件、在线协作
- **日常沟通**：微信、QQ、腾讯会议、钉钉、飞书
- **开发者**：VS Code、Git、Docker、DBeaver、Postman
- **创作者**：剪映、DaVinci Resolve、Blender、Krita、GIMP、OBS Studio
- **系统维护**：Rufus、Ventoy、CrystalDiskInfo、DiskGenius、VirtualBox
- **远程协作**：ToDesk、向日葵、坚果云、LocalSend

## 📝 选择建议

- **只想省心装机**：Edge / 7-Zip / Everything / Snipaste / 搜狗输入法 / Ditto / VLC / PowerToys 基本闭眼装。
- **学生 / 轻办公**：WPS Office / PDFgear / 腾讯文档 / 石墨文档 / 坚果云 / 网易邮箱大师。
- **开发者常用**：VS Code + Git + Windows Terminal + Docker + DBeaver + Postman。
- **创作者常用**：剪映专业版（入门）/ DaVinci Resolve（进阶）+ Blender + Krita + OBS Studio + HandBrake。
- **系统维护**：Ventoy / Rufus + CrystalDiskInfo + DiskGenius + VirtualBox。

## ⚠️ 最后提醒

- 从官网或官方商店下载，别碰”XX软件园”之类的第三方打包站。
- 装软件不是越多越好，够用就行。电脑不是软件博物馆。
- 如果你不确定装哪个，看每张表里**第一个推荐**通常最稳。
